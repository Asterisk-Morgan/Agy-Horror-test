# M.M.I.C. - Phantom Organism Incident -
**スマートフォン & PC 両対応 SFサバイバルホラー・アドベンチャーゲーム**

現代怪異・人工生体研究所「M.M.I.C.」で発生した壊滅的バイオインシデント。
黒いコートを纏う青年**ミダル**は、施設で保護されていた謎の少女**ユメ**を護衛しつつ、怪異が跋扈する閉鎖施設からの脱出を目指す。

---

## 🎮 特徴とゲームシステム

### 1. スマートフォン & PC ハイブリッド対応
- **スマートフォン**:
  - 画面左側エリア：直感的なバーチャルアナログジョイスティック（タッチ追従）
  - 画面右側エリア：大型バーチャルボタン群（【刀】近接斬撃、【射撃】遠距離射撃、【切替】武器ローテーション、【調べる】ドア・アイテム調査、【装填】リロード）
  - 全画面表示対応、マルチタッチ対応、バイブレーション触覚フィードバック（対応端末）
- **PC (キーボード & マウス)**:
  - 移動: `W, A, S, D` または 矢印キー
  - 照準: マウスカーソル方向
  - 攻撃: `左クリック` または `Space`
  - クイック直刀攻撃: `右クリック` または `F` キー
  - 武器切り替え: `1`, `2`, `3` または `Q` キー
  - リロード: `R` キー
  - 調べる / 決定: `E` または `Enter` キー
  - 資料アーカイブ手帳: `J` または `Tab` キー
  - サウンド切替: 画面右上 `🔊` ボタン

### 2. 主人公「ミダル」の携行武装
- **対怪異高周波直刀 (Chokuto)**
  - 近接戦用。怪異の生体筋繊維を断ち切るために打たれた白刃。
  - スタミナを消費して扇状（約135度）の範囲攻撃を放ち、怪異を怯ませノックバックさせる。弾薬無制限。
- **XDM-40 (.40 S&W)**
  - 大口径セミオート拳銃。装弾数16発。
  - 高いストッピングパワーと単発火力を誇り、中距離の敵を確実に撃退する。
- **MP7A1 (4.6×30mm PDW)**
  - 高速連射サブマシンガン。装弾数40発。
  - 圧倒的な制圧力で、群がる怪異や高速突進する怪異を蜂の巣にして足止めする。

### 3. 同行者「ユメ」と護衛システム
- 白い研究衣を纏った謎の少女。ミダルの後を健気について歩く。
- 怪異が接近すると身をすくめてミダルの背後に隠れ、危険を警告する。
- **生体共鳴オーラ**: ユメの近くにいるとミダルのスタミナ回復速度が大幅に向上する。
- 近くにある研究資料や弾薬箱、キーカードを発見するとミダルに教えてくれる。
- **ゲームオーバー仕様**:
  - ミダルの生命力 (HP) がゼロになると発生。
  - ミダルが膝をついて倒れ、ユメへ逃げるよう促す言葉を残して画面が暗転。
  - **ユメへの危害は一切描写されません。**

### 4. 敵「怪異 (Cryptid Organisms)」
幽霊ではなく、未確認生命体や都市伝説、民俗伝承の存在が遺伝子工学・生体技術により実体（肉体）を持った生物群。
- **八尺の腕 (Hachishaku Lurker)**:
  - 長身白装束の怪異。腕が油圧シリンダーのように急伸し、遠距離からミダルを突く。
- **人面獣キメラ (Face-Hound Chimera)**:
  - 人間の顔と獣の体を併せ持つ高速怪異。ジグザグ走りで急接近して飛びつく。
- **這行の刃 (Crawl Slicer / テケテケ)**:
  - 下半身を切除され両腕にチタンブレードを移植されたサイボーグ怪異。超速の直線突進を行う。
- **生体結晶塊 (Kotori Spore-Carrier)**:
  - 呪物結晶を心臓に宿す歩行肉塊。周囲全方位へ有毒な生体棘を散弾発射する。
- **被験体零号・ウロボロス (Subject Zero: Ouroboros)**:
  - 地上ゲートの直前に立ちはだかる巨大複合怪異。

### 5. 施設内研究資料・アーカイブ閲覧システム

## 🕹️ プレイ方法

### ローカルでの起動
本ゲームは外部ライブラリへの依存がなく、静的Webサーバーがあれば即座に動作します。

```bash
# Pythonでローカルサーバーを起動する場合
python3 -m http.server 8080
```
起動後、ブラウザで `http://localhost:8080/` にアクセスしてください。
スマートフォンから遊ぶ場合は、同じWi-Fiネットワーク上のPCのローカルIPアドレス、またはGitHub Pages等の静的ホスティングにデプロイすることで、ブラウザから快適にプレイできます。
